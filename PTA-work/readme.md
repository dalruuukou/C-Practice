## 一些踩坑记录

写这些题过程中值得记下来的几点：

1. **水仙花数那题**（`narcissistic`）—— 最容易漏的是"区间非法"的情况：`lower > upper`、或者区间没落在 100~999 内，都要单独判断并输出 `Invalid Value.`。
2. **3 的乘方表**（`powersof3tables`）—— 用 `pow()` 返回浮点有精度隐患；文件末尾保留了用 `long long` 递推的版本（`res *= 3`），既没有精度问题也不会溢出。**递推比 `pow()` 更稳**。
3. **最大公约数**（`gyhegb`）—— 一开始用暴力递减/递增，能过但效率差；注释里留了**辗转相除法**的版本，最小公倍数用 `(m / gy) * n` 先除后乘，避免溢出。
4. **火车运行时间**（`trainworkingtime`）—— 关键是分钟不够减时向小时借 1（借 60 分钟），不要用浮点算时间。
5. **数根**（`shugen`）—— 外层 `while (n >= 10)` + 内层拆位求和，两层循环才能反复收敛到一位数。
