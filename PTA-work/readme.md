## 一些踩坑记录

写这些题过程中值得记下来的几点：

1. **水仙花数那题**（`narcissistic`）—— 最容易漏的是"区间非法"的情况：`lower > upper`、或者区间没落在 100~999 内，都要单独判断并输出 `Invalid Value.`。
2. **3 的乘方表**（`powersof3tables`）—— 用 `pow()` 返回浮点有精度隐患；文件末尾保留了用 `long long` 递推的版本（`res *= 3`），既没有精度问题也不会溢出。**递推比 `pow()` 更稳**。
3. **最大公约数**（`gyhegb`）—— 一开始用暴力递减/递增，能过但效率差；注释里留了**辗转相除法**的版本，最小公倍数用 `(m / gy) * n` 先除后乘，避免溢出。
4. **火车运行时间**（`trainworkingtime`）—— 关键是分钟不够减时向小时借 1（借 60 分钟），不要用浮点算时间。
5. **数根**（`shugen`）—— 外层 `while (n >= 10)` + 内层拆位求和，两层循环才能反复收敛到一位数。
6. **百砖百人搬**（`baizhuanbairenban`）—— 已知总人数后，小孩人数可以由前两类人数相减得到，只需枚举男人和女人；同时要检查小孩人数是否为偶数。
7. **猜数字**（`caishuzi`）—— 注意"猜中"要先于"次数用完"判断；第一次猜中、前三次内猜中和之后猜中对应的输出不同。
8. **月份对应季度**（`yuefendejidu`）—— 相邻月份的季度相同，可以让多个 `case` 共用一个分支，利用 `case` 穿透减少重复代码。
9. **成绩多分支**（`duofenzhi`）—— 用 `num / 10` 把整个分数段归并为一个 `switch` 分支，比逐一分段写 `if` 更简洁；同时要把 100 分和非法输入单独考虑。
10. **泊车收费**（`bocheshoufeiwenti`）—— 先分离完整天数和当天剩余小时，避免跨过 24 小时后继续累加超时费用；超过首时段不足一个计费单位时用 `ceil()` 向上取整，并通过封顶金额限制当天费用。
11. **查询水果价格**（`chaxunshuiguojaige`）—— 循环读取时要同时处理退出编号 `0` 和最多查询 5 次的上限；无效编号也要给出明确的默认输出。
12. **兔子繁衍**（`tuzifanyan`）—— 兔子数量按斐波那契规律增长；`n <= 1` 需要单独处理，否则初始两个月的设置会导致答案偏大。
13. **三角形面积与周长**（`sanjiaoxingmianjihezhoucahng`）—— 先用任意两边之和大于第三边判断能否构成三角形；海伦公式中的半周长要用 `2.0` 做浮点除法，避免整数截断。
14. **位数与各位和**（`weishuyugeweishudehe`）—— 每轮同时执行 `n % 10` 和 `n / 10`，一次循环即可得到答案；如果题目允许输入 0，还需单独规定 0 的位数。
15. **查找完数**（`zhaowanshu`）—— 枚举每个候选数时都要先把因子和清零，因子只需检查到 `i / 2`；另外要单独记录是否找到完数，否则区间内没有结果时无法正确输出 `None`。
